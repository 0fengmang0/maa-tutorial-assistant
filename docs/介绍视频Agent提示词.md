# 项目介绍提示词

请为「MAA 教程助手」制作介绍视频，下面是项目的主要功能：

MAA 教程助手是一个基于 MaaFramework 的 Windows 本地工具，帮助用户自动完成 MAA 新手教程。

- 打开助手后，勾选任务并点击「开始」，程序会自动寻找用户已经打开的 MAA 教程窗口。
- 操作前记录原主题，切换到深色，然后通过视觉识别和窗口操作逐步完成教程。
- 点击加号可添加「恢复原主题」任务，完成教程后恢复之前的亮色、深色或与系统同步设置；不添加则保持深色。
- 界面采用 MAA 风格的深色三栏布局：左侧选择任务，中间查看任务详情，右侧切换运行日志与当前任务日志。
- 支持全选、清空、停止和继续，运行时也可按 F8 中断。
- 本地运行，不连接游戏、不运行游戏任务。它是独立项目，非 MAA 官方产品。

当前完整流程已在 MAA v6.21.3 简体中文环境验证，其他版本尚未适配。
