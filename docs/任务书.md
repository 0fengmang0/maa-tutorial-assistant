# MAA 教程助手开发任务书

版本：0.3 · 2026-11-04（Asia/Shanghai）

## 1. 目标与正式入口

在 `D:\AI_work_space\project_next\maa-tutorial-assistant` 开发一个轻量 Windows 程序，使用 MaaFramework 操作用户已打开的 MAA，完成其新手教程。界面 HUD 与当前 MAA 的深色界面保持一致。

本轮先建立任务书和开发过程文档。程序实现、实际启动、自动化回归和可用交付按下列阶段推进，不能以文档或构建成功代替验收。

## 2. 已确认范围

### 功能一：自动通过教程

1. 双击启动后等待；用户点击「开始」后自动扫描已经打开的 MAA 窗口。
2. 排除助手自己的窗口；校验目标进程、窗口与教程页面。
3. 唯一有效目标时自动绑定。没有目标时给出等待/重试状态；多个候选时停止输入，提示只保留一个目标。
4. 通过 MAA 界面读取原始主题选项，先持久保存，再通过设置切到深色。
5. 确认深色生效后，完成全部教程页面及交互任务。
6. 通过教程退出及正常界面出现确认完成。

教程步骤必须依靠 MaaFramework 的截图、识别和窗口输入推进，不使用「跳过」替代，也不直接改完成标记。

### 功能二：恢复原主题

1. 助手任务列表提供「＋」菜单。
2. 菜单可以添加一项「恢复原主题」任务。
3. 若教程正在运行，恢复任务排在教程之后；若尚未运行或教程已完成，添加并勾选后，点击「开始」执行。
4. 通过目标 MAA 的设置将主题恢复到操作前的原始选项。
5. 原选项为「跟随系统」时恢复该选项，不能仅按当时画面恢复成浅色。
6. 原主题本来就是深色时，该任务安全结束并说明无需更改。
7. 未添加该任务时，教程结束后保持深色。

作用对象是目标 MAA；助手 HUD 始终保持深色。

### 非目标

- 游戏自动化、多账号、批量窗口和模拟器管理。
- 教程在浅色主题下的完整识别适配。
- 远程服务、AI 模型、订阅、自动更新和插件系统。
- 修改原 MAA 安装或用户配置来伪造已通过教程。

## 4. 教程操作清单

本地 v6.21.3 页面顺序：界面设置 → 使用指引 → 游戏设置 → 连接设置 → 任务设置 → 性能设置 → 更新设置。

任务演示的完成条件包括：

- 保留开始唤醒和默认理智作战任务。
- 添加一项理智作战，将关卡设为当期剿灭。
- 重命名为与默认名称不同的任务。
- 将该任务移到默认理智作战上方。
- 启用周计划，勾选周一和周日。
- 添加切换主题任务，并将其排在末尾。
- 在演示主题列表中添加「夜间」。

上述演示内的「切换主题任务」属于目标教程内容，和助手通过「＋」添加的「恢复原主题」是两个不同层级的任务，代码和文案须区分。

## 6. 关键实现约束

- 不硬编码用户安装路径或窗口句柄。
- 主题状态必须在第一次改动之前保存；重试或重启不能用已切换的深色覆盖原主题。
- 持久状态绑定到本次目标身份，防止 PID 复用或多开时恢复到错误窗口。
- 每个动作都需要识别前提、超时和后置验证；禁止盲目重复点击。
- WPF 弹出菜单可能拥有独立窗口，必须将输入限制到同一目标进程及其所属窗口。
- 允许用教程提供的上移/下移菜单完成排序，不强求鼠标拖拽。
- 停止后不继续发送输入；窗口消失或识别失效时停止。
- 核心和必要模型在本地运行，不依赖云端模型服务。

## 7. 验收矩阵

| 场景 | 预期 |
| --- | --- |
| 深色教程启动 | 自动找到目标并通过全部教程 |
| 浅色教程启动 | 先保存浅色选项、切深色，再通过教程 |
| 跟随系统且当前浅色 | 保存「跟随系统」、切深色；恢复任务恢复「跟随系统」 |
| 加号添加恢复任务 | 列表显示该任务，并在教程之后按顺序恢复原主题 |
| 不添加恢复任务 | 教程通过后保持深色 |
| 无目标或多个候选 | 明确提示，不向无关窗口输入 |
| 运行中点击停止 | 取消等待并停止后续输入 |
| 页面变化或超时 | 记录失败步骤与截图，不继续猜测操作 |
| 应用中断后重试 | 原主题记录不丢失、不被深色覆盖 |
| 数据保护 | 原安装目录的文件数量、大小和 SHA256 与基线一致 |

完整流程至少从同一初始快照连续通过 3 次；主题恢复三类场景单独留证。尚未运行的场景标记「未验证」。

## 8. 轻量化与发布

优先 WPF 框架依赖部署，仅携带 Windows x64 所需 MaaFramework 组件和必要识别资源。实际可分发体积、工作集、启动时间在 S5 测量后报告，不将已有 MAA 安装大小算成助手体积。

不携带本机 MAA 用户配置、测试副本、日志、截图、凭据或开发 SDK。发布前保留各依赖许可证和来源；若复用 MAA 源码或样式代码，按其 AGPL-3.0-only 义务处理。MAA Logo 和游戏素材不视为已授权。

## 9. 预计开发投入

原教程固定环境版估算为 3–6 小时；本次增加主题记录、强制切换、恢复任务和相应验证后，首个可用版本暂估 **4–8 小时**。实际依赖接入、WPF 弹窗截图与输入兼容性可能影响耗时，开发过程文档持续记录实际情况。
